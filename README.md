Forecast how many GTA VI players earn each trophy in week one. Round 2: a logit-scale trend plus counts model for live histories, and a scenario-quantile dilution model for frozen ones — each quantile read off the refresh dilution curve at its own newcomer earn fraction, tuned to beat the pure-dilution bet in every refresh scenario.
